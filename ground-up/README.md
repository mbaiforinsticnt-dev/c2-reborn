# C2-01 Ground-Up

A from-scratch Nokia C2-01 / Series 40 reconstruction built from original firmware assets and explicit evidence contracts.

## Evidence policy

Physical C2-01 evidence wins. RM-721-specific evidence is next. RM-722 / product 059F5P7 content is labelled inference. Generic SDK evidence is last. Conflicts are recorded, never averaged.

## Current release

v0.1 contains the Phase 0 evidence ledger and the Phase 1 exact-pixel Black-theme LCD shell. It is a prototype, not firmware or full emulation. Fallback fonts are not Nokia fonts.
