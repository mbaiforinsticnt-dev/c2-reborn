# C2 Reborn v4.4 maximum-depth audit register

Audit started 2026-09-15. Findings report due to parent before 16:30 BST. Fixes follow the report. One parent-authorized rough-edge snapshot was published during audit for third-party review; later fixes remain held until the next approved deployment.

Evidence order: owner physical C2-01 photos/video, live Nokia S40 SDK LCD captures, official guide. A rendered screen with no matching source is an evidence gap, not a parity pass.

## Coverage method

- Extracted 89 named page states from screen data, route destinations and page-specific logic. See `page-inventory.txt` and `static-page-map.json`.
- Rendered all 89 page states at 390 x 900 in a clean local Chrome profile. `runtime-page-snapshot.json` records screen text and softkeys for each state; four visual contact sheets were generated outside the repo for pixel review.
- Structural audit covers every physical key route, softkey, options path, state mutation, destination, and fallback page.
- Matching visual claims are made only for named evidence files in `evidence/v4.4/README.md`.
